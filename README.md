# 출구 전략 3 (Exit Strategy 3)

TV 예능 〈출구 전략〉을 1:1 보드게임으로 옮긴 웹 게임입니다. 설치 없이 `index.html` 파일 하나로 동작하며, PC·휴대폰 어디서나 브라우저로 즐길 수 있습니다.

## 플레이 방법

- **목표**: 내 일반 말 **2명**을 출구로 탈출시키거나, 상대 일반 말 **3명**을 제거하면 승리.
- **배치**: 자기 진영(왼쪽=1~3열 / 오른쪽=5~7열)에 배치. 양 팀이 일반 말 5개를 번갈아 놓은 뒤, 마지막에 헌터를 번갈아 놓습니다. 일반 말은 출구와 같은 행/열에는 놓을 수 없고, 헌터는 반드시 노란 구역에 배치합니다.
- **일반 말**: 상하좌우 직선으로만 이동, 다른 말이나 벽에 닿으면 멈춤.
- **탈출**: 출구를 그냥 지나가는 건 탈출이 아니며, 직선 이동 끝에 **출구 칸에 딱 멈출 때**만 탈출(출구 바로 뒤에 벽이나 말이 있어야 함).
- **헌터(H)**: 상하좌우 한 칸씩 이동. 그 칸에 상대 일반 말이 있으면 즉시 제거. 헌터끼리는 못 잡고, 출구는 지나가거나 탈출할 수 없습니다.

## 게임 보드

- 7×7 격자 기반의 37칸 십자형(180° 회전 대칭) 보드, 가운데가 출구입니다.
- 노란 구역(왼쪽 1열·오른쪽 7열의 3칸)은 헌터 배치 구역입니다.

## 컴퓨터 대전 · 분석

- **사람 vs 컴퓨터** 모드 + 난이도 5단계(쉬움·보통·어려움·매우 어려움·🧠 학습형 MCTS), **무르기** 지원.
- **🔍 분석 표시**: MCTS 엔진으로 각 수의 **승률 %**와 **최적수(blue spot)**를 알파고식으로 **실시간** 표시. 강도: 빠름/정밀/심층/무제한. 보드 아래 **승률 추이 차트(📈)**로 복기 가능.
